總覽

經典翻牌配對，卡面換成 Bobathon 的角色

規則跟小時候玩的翻牌記憶遊戲一樣：桌上蓋著一排卡牌，每次翻開兩張， 圖案相同就配對成功，不同就翻回去，直到全部配對完成。 這次卡牌裡藏著三個 Bobathon 主角的 logo——IBM、IBM Bob、中鋼， 配上幾組表情符號湊成完整的一副牌。

起手 Prompt

複製這一整段，貼給 Bob

開始之前，先確認你已經在專案資料夾的終端機裡——這段 prompt 的第一步會直接抓圖片素材。

先在終端機執行以下指令，取得 logo 圖片素材：

git clone <PLACEHOLDER_REPO_URL>
cd Memory-Match

資料夾裡有一個 assets/ 目錄，裡面有三張圖：
- assets/IBM-rebus-logo.png（IBM logo）
- assets/IBM-Bob-logo.png（IBM Bob logo）
- assets/CSC-logo.png（中鋼 logo）

接著幫我做一個 HTML 檔案（可以內嵌 CSS 和 JavaScript，不用任何框架），是一個翻牌配對遊戲（Memory Match）：

- 總共 12 張卡牌、6 組配對：3 組是上面那三張 logo 圖片（各出現 2 次），另外 3 組請你自己挑 3 個好看的表情符號（例如水果），每個表情符號也出現 2 次，湊滿 12 張
- 遊戲開始時卡牌要隨機打亂排列，卡牌背面統一是同一個圖案或顏色，看不出正面是什麼
- 點擊卡牌會翻開，翻開時要有 3D 翻轉動畫，不要用圖片直接切換
- 一次最多翻開兩張卡牌：兩張圖案相同就配對成功，讓這兩張保持翻開，並且要有明顯的成功特效（例如放大一下、發光或彈跳動畫）；兩張不同的話，短暫停留一下讓玩家看清楚，再自動翻回背面
- 畫面上要有一個正計時碼表，從玩家翻開第一張卡開始往上計時，全部配對完成時停止
- 用 localStorage 記錄「最少翻牌次數」和「最快完成時間」這兩個最佳紀錄，每次玩完都跟紀錄比較，如果打破紀錄要明顯地告訴玩家
- 全部配對完成後，顯示一個完成畫面，內容包含這次花了多少時間、翻了幾次牌，並提供一個按鈕可以清除畫面、重新洗牌開始新的一局

整體風格希望活潑好玩、色彩豐富，適合學生用，不要做成嚴肅的企業風格介面。
